# WAD laravel react activity 2 & 3

## Overview
Monarch's Archive is a manhwa and manga tracking system built with Laravel and React that allows users to manage their reading lists and track chapter progress. It features a clean dashboard for organizing series, logging read chapters, and saving personal notes.
